# BRAIN-TO XA60 protocol index

This page is a brief index to the BRAIN-TO XA60 collections. Zenodo is the
single source for downloadable protocol packages and detailed acquisition
parameters.

## Collections

| Platform | Protocol sets | Zenodo package |
|---|---|---|
| Siemens XA60, 3 T | Anatomy, fMRI, diffusion, ASL | Link to be added |
| Siemens XA60, 7 T | Anatomy, fMRI, diffusion | Link to be added |

The 7 T collection does not include a product ASL protocol. To discuss 7 T ASL
options, email [sriranga.kashyap@utoronto.ca](mailto:sriranga.kashyap@utoronto.ca).

## Use the right collection

Start with the [3 T](3T/README.md) or [7 T](7T/README.md) collection page.
Use the matching Zenodo package and accompanying parameter material when it is
available. Do not combine 3 T and 7 T protocol settings or assume that a
protocol is suitable for a different coil or scanner configuration.
